## 2026-04-05 - [Template-level Security Hardening]
**Vulnerability:** Redundant/conflicting CSPs, missing SRI on CDNs, and potential tabnabbing on external links.
**Learning:** Consolidating security headers at the template level ensures a consistent security posture across all generated pages and reduces browser confusion from multiple directives.
**Prevention:** Regularly audit theme templates for outdated script references and ensure all external resources use SRI and secure link attributes.
